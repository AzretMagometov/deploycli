# deploycli

Инструмент подключает деплой к существующему проекту на Docker Compose. Он сканирует проект, спрашивает недостающее и генерирует конфигурацию деплоя на VPS: пайплайн CI/CD, compose-файл и правила Traefik. Он же готовит сервер и накатывает обновления в подключённый проект.

## Состояние

Проект проектируют. Кода пока нет. Решения принимают через карту в beads:

```
bd list -t epic -l wayfinder:map
```

## Границы

Цель деплоя — VPS с Docker Compose и Traefik. Traefik работает на уровне хоста и обслуживает несколько проектов.

Первая версия поддерживает GitHub Actions и Forgejo Actions. GitLab и Jenkins получают документированный интерфейс расширения без реализации.

Мониторинг вне границ проекта. Деплой без простоя вне первой версии.
